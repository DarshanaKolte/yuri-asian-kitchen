# YURI - The Asian Kitchen Premium Animated Website

A luxury animated React website for a Pan-Asian restaurant in Akurdi, Pune. Built with React, Vite, Framer Motion, GSAP, Lucide icons, and a small Express booking API.

## Run frontend
```bash
npm install
npm run dev
```

## Run booking backend
Open a second terminal:
```bash
npm run server
```
Bookings will be stored in `server/bookings.json`.

## Deploy frontend on Vercel
1. Upload this folder to GitHub.
2. Import the repo in Vercel.
3. Build command: `npm run build`
4. Output folder: `dist`
